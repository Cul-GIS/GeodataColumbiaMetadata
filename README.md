This repo holds the current Aardvark JSON metadata for the Columbia University Libraries' Geospatial collections. These records are used for ingest into the Library [Geoblacklight catalog](https://geodata.library.columbia.edu/).

All records live in [`aardvark_json/`](aardvark_json/), one JSON file per resource, following the [OpenGeoMetadata Aardvark schema](https://github.com/OpenGeoMetadata/metadata-aardvark).

This is the current, actively maintained metadata repo. Older XML-era metadata and processing scripts remain archived at [ssitari/GeodataColumbiaMetadata](https://github.com/ssitari/GeodataColumbiaMetadata) for historical reference only and are no longer updated.

This repo is primarily for internal use. If you need information here, or otherwise have questions, please reach out to data@columbia.edu.
